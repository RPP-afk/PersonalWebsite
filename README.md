# My Personal Website

This repo will contain the source code to host my personal website on GitHub. This will be a place where I write up my coding projects - like a coding challenge journal if you will, as well as writing up my own personal documentation for technologies I intend to use in my future home lab.

The structure of this repo is as follows: 

- Coding Project Pages:
  These are to be stored in the `coding_challenges/` directory.
- Home Lab Pages:
  These are to be saved in the `home_lab/` directory.
- Useful resources and other documentation:
  These will be saved in the `resources/` directory.

This site will likely evolve as I work on it, so the above structure may well change from time to time.
